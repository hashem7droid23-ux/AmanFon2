## 🚀 نبذة عن التطبيق
تطبيق أمان فون هو منظومة وطنية ذكية متكاملة تهدف إلى الحد من سرقة الهواتف في الجمهورية اليمنية وربط محلات الصيانة والبيع بنظام تنبيهات فوري موحد وقاعدة بيانات وطنية لفحص أرقام IMEI.

### 🌟 أبرز المميزات:
1. **فحص أرقام IMEI:** فحص فوري ومتقدم لأرقام IMEI والتأكد من صحتها بخوارزمية Luhn ومطابقتها مع قائمة الهواتف المسروقة والمبلغ عنها.
2. **تسجيل الدخول المتعدد:** دعم تسجيل الدخول الآمن بحساب Google المعتمد عبر Firebase، والبريد الإلكتروني، ورقم الهاتف اليمني (+967).
3. **تنبيهات فورية عاجلة:** إرسال إشعارات وتنبيهات عاجلة لكافة محلات بيع وصيانة الهواتف عند تسجيل أي بلاغ سرقة في أي محافظة يمنية.
4. **دليل الأمان لمحلات الجوالات:** إرشادات قانونية وتقنية متكاملة وأرقام الطوارئ في اليمن (النجدة، البحث الجنائي، وشركات الاتصالات).
5. **يعمل بدون إنترنت (Offline-First):** تخزين محلي متقدم عبر Room Database مع مزامنة سحابية حية عبر Cloud Firestore.

## ⚙️ طريقة بناء وتحميل ملف APK عبر GitHub تلقائياً:

تم إعداد ملف **GitHub Actions Workflow** التلقائي في المسار:
`.github/workflows/build-apk.yml`

### خطوات الحصول على ملف الـ APK الجاهز من GitHub:
1. عند عمل **Push** لهذا المشروع إلى حسابك في **GitHub** (من خلال زر Push to GitHub في قائمة AI Studio).
2. اذهب إلى مستودع المشروع على GitHub واضغط على تبويب **Actions**.
3. ستجد أن مهمة **"Build Aman Phone APK"** بدأت بالعمل وبناء التطبيق تلقائياً.
4. بمجرد اكتمال البناء (ستظهر علامة صح خضراء ✅):
   - اضغط على العملية واذهب إلى قسم **Artifacts** في أسفل الصفحة.
   - قم بتحميل ملف **`AmanPhone-debug-apk`** الجاهز للتثبيت المباشر.
5. يمكنك أيضاً إنشاء **Release** أو تشغيل الـ Workflow يدوياً عبر زر **Run workflow** في GitHub وسيقوم بإنشاء إصدار جاهز للتحميل المباشر.
