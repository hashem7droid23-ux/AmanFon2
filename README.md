## عن أمان فون

أمان فون تطبيق يساعد أصحاب الهواتف ومحلات البيع والصيانة على مراجعة بلاغات السرقة والفقدان قبل التعامل مع جهاز. يجمع وصف الهاتف وصوره ومكان الحادثة ووسائل التواصل مع صاحب البلاغ، ويتيح البحث برقم IMEI.

## خدمات التطبيق

| الخدمة | ما يمكنك فعله |
| :--- | :--- |
| **فحص هاتف** | البحث برقم IMEI عن بلاغات السرقة والفقدان النشطة المسجلة في أمان فون. |
| **تسجيل بلاغ** | إضافة بلاغ عن هاتف مسروق أو مفقود أو معثور عليه، مع وصف الجهاز ومكان الحادثة. |
| **صور الجهاز** | إرفاق حتى ثلاث صور تساعد على التعرف على الهاتف وعلاماته المميزة. |
| **مسح الباركود** | إدخال IMEI والرقم التسلسلي S/N بقراءة الباركود بدل كتابته يدويًا. |
| **التواصل** | الاتصال بصاحب البلاغ أو مراسلته عبر واتساب من تفاصيل البلاغ. |
| **متابعة بلاغك** | توثيق استرجاع الهاتف أو حذف بلاغك وفق صلاحيات حسابك. |

## تحميل التطبيق

**[انتقل إلى صفحة التحميل](https://github.com/hashem7droid23-ux/AmanFon2/releases/tag/v1.0-apk)**، ثم افتح قسم **Assets** واختر ملف **AmanPhone-debug.apk**.

النسخة الحالية تجريبية. حمّل التطبيق من الرابط الرسمي أعلاه، ولا تشارك كلمة المرور أو رمز التحقق مع أي شخص.

## كيف تستخدمه؟

1. **سجّل الدخول** بالطريقة المتاحة لك داخل التطبيق.
2. **افحص الجهاز** بإدخال رقم IMEI المكوّن من 15 رقمًا. يمكنك إظهاره على الهاتف بطلب `*#06#`، أو مسح الباركود الموجود على العلبة.
3. **راجع النتيجة** وتفاصيل البلاغ إن وُجد. إذا فقدت هاتفك، سجّل بلاغًا ببيانات دقيقة وصور واضحة ووسيلة تواصل صحيحة.

## قبل شراء هاتف

> عدم وجود بلاغ في أمان فون ليس إثبات ملكية ولا ضمانًا أن الجهاز غير مسروق. طابق IMEI مع الجهاز والعلبة والفاتورة، واطلب إثبات الملكية قبل الدفع.

التطبيق يعرض البلاغات المسجلة فيه فقط؛ ليس سجلًا حكوميًا ولا وسيلة لتحديد موقع الهاتف.
